# Tripleten web_project_around_pt

Uma página web interativa de galeria de fotos onde os utilizadores podem explorar paisagens, editar informações de perfil e gerir cartões de lugares.

## 📝 Descrição do Projeto
uma página onde usuários podem adicionar, remover e curtir fotos.

*Atualmente esta em desenvolvimento*

## 🛠️ Tecnologias e Técnicas Utilizadas

HTML,CSS e JavaScript.
** Funcionalidades em desenvolvimento, até o momento foi criado um array de objetos e iteração com `forEach()`.
